# 健康喝水 v3.0.0-beta.1

2026-10-23。v3 首个公开预览版，重点是离线记录、数据保护和 Android 提醒。

## 下载与使用

- [GitHub Release](https://github.com/yjwwuwei/health-water-app/releases/tag/v3.0.0-beta.1)
- [网页版](https://yjwwuwei.github.io/health-water-app/)
- `health-water-v3.0-dev.apk`：Android 开发包，安装后名称为「健康喝水 Dev」，包名 `com.yjwwuwei.healthwater.dev`，包内版本 3.0.0/300。
- `health-water-v3.0-web.zip`：适用于 `/health-water-app/` 路径的静态站点文件，需通过 HTTP(S) 服务访问。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。

Android 包使用开发签名，作为独立预览安装，可以与旧版并存。它不能覆盖升级旧应用，也不会自动读取旧包中的记录。请保留旧版及其中的数据，不要通过卸载旧版尝试迁移。正式覆盖升级仍需确认旧签名和完成真机验收。

## 主要变化

- 重做「今天」「历史」「设置」页面，支持逐笔记录、真实撤销、补记、编辑、删除和明日生效的饮水目标。
- 本地优先保存，提供 JSON 导入预览、冲突选择和导出；新旧数据库隔离，迁移保留原文备份，旧日汇总不伪造记录时间。
- Android 原生提醒支持通知权限、清醒时段、15 分钟稍后提醒、达标暂停和重启恢复。Web 版不提供后台提醒。
- 趣味姿势打卡默认关闭，模型随 APK 提供，画面在本机处理；打卡不会自动记账。
- Web 支持首次访问后的离线记录与明确确认更新。
- 代码采用 MIT 许可证，第三方模型和组件保留各自许可。

## 验证

累计 43 项自动化测试通过：23 项单元/React、6 项 Firestore 模拟器、8 项浏览器、3 项 Android 时间计算和 3 项 Android 原生集成测试。另完成 6 项 Android 安装版流程检查，以及未打开应用时的真实模拟器重启提醒恢复检查。

本次发布复核了 57 项源码/构建输入及安装包、Web 包的哈希。GitHub CI 包含 Web 检查、Rules 测试、浏览器测试和 Android 构建；完整证据见 [验证记录](../v3-verification.json) 与 [Android 验收](../V3_ANDROID_ACCEPTANCE.md)。

## 预览范围

此版本提供 v3.0 本地功能。邮箱账号、增量同步和榜单属于 v3.1 云功能预览源码，本次不部署生产 Firebase 服务，也不发布云预览构建。

实体手机后台与节电策略、真实摄像头差异、旧签名覆盖升级仍需验收。提醒属于系统调度，可能因系统策略延迟。2026-10-22 的生产依赖审计为 0 告警；开发工具仍有 9 个告警包，对应 3 个独立公告，详见 [依赖审计](../V3_DEPENDENCY_AUDIT.md)。

反馈时请说明设备型号、系统版本、复现步骤，以及是否影响记录保存。不要在公开 issue 中上传个人备份或账号凭据。
