# v3 隐私说明

默认离线版将记录、目标、迁移备份和设置保存在本机 IndexedDB。没有广告、分析 SDK 或相机画面上传。

Android 系统备份可能包含本地应用资料，取决于用户的操作系统设置。JSON 导出包含个人饮水记录，由用户选择保存位置。

相机仅在用户主动开始姿势打卡后使用；后台、关闭、失败、完成时停止相机。Web 首次使用下载固定模型，Android 随包提供。

Android 提醒需要通知授权，可在设置中关闭。提醒计划、当天达标状态和下一次调度均留在本机。系统节电和厂商策略可能延迟提醒。

云预览使用 Firebase Auth 邮箱登录，私有云数据包括 UID 下的记录、目标、汇总、同步序列、回执和榜单授权。Rules 限制账号只能访问自己的资料。

登录不自动认领游客数据。退出后未同步内容保留在原账号的本地空间。设备存储不额外加密，应依赖系统锁屏和设备访问控制。

榜单默认关闭，主动加入只公开昵称、自然周/月及达标天数，不公开邮箱、逐笔时间、画面或饮水总量。退出需联网删除摘要，失败明确提示。账号级授权避免其他设备自动重新发布。

本轮未部署生产 Rules，未修改线上用户资料。
