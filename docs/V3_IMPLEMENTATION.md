## 数据契约

DrinkEntry 保存发生时间、保存时区、当地日期、整数毫升数及来源。LegacyDaily 保留旧 UTC 日期和来源，无虚构时间。GoalPolicy 按生效日期唯一标识；历史没有目标时显示未知。DaySummary 为本地派生索引，不作为同步真相。

实体和待同步操作同一 IndexedDB 事务写入。删除保留永久 tombstone；历史备份导入不能恢复同 ID 已删除记录，需要重新新增。重复导入相同内容不产生新的同步操作。同步只查询序列后的变更，每页 100 条；离线多端新增合并、同条编辑显式冲突，断线后回执保证不重复写入。

云端每次有效变更原子更新实体、账号序列、操作回执。账号切换取消旧 UI 回调并隔离持久队列，已经发出的旧账号请求仍只能影响原 UID。冲突解决采用用户最新的本地修改，而非弹出冲突时的过期副本。

旧云迁移预览无冻结副作用。确认导入成功后，同事务设置待冻结标记；同步流程再执行账号 migrated 标记，失败可重试。冻结后的旧数据仍可读取，可再次对照迁移期间的旧端写入；不删除旧云原文。

榜单授权存于账号私有 preferences；公开文档只含昵称、当前周/月和达标天数。自动刷新不能替代显式加入，其他设备退出后不能被旧本地缓存重新加入。旧日汇总不能通过补一笔小额记录变成达标分数。

## 自动化验证

本轮最终命令、计数和产物信息以同目录 v3-verification.json 为准。

- npm run check：TypeScript、ESLint、23 项单元/React 回归，包括旧原生 SW 注销后退出控制及保存事务等待。
- npm run test:rules：6 项 Firestore 模拟器测试，包含权限、回执、两份数据库同步、冲突、删除、跨设备榜单退出。
- npm run build 与 npm run test:e2e：8 项生产浏览器测试，包含离线重载、模型实际推理、焦点、迁移、目标和 SW 升级。
- Android：3 项提醒时间计算测试、开发 APK 编译；后续在 API 36 模拟器实际执行 3 项 instrumentation 测试，均通过。自动化测试累计 43 项。
- npm audit --omit=dev：0 项漏洞。全树仍有 9 个开发工具告警包（3 high、6 moderate），对应 3 个独立安全公告；不是 9 个独立漏洞。兼容版本、实际调用及 Vite 内嵌副本已专项核查，详见 [开发依赖审计](V3_DEPENDENCY_AUDIT.md)。当前范围内无兼容修复，未通过降级或强制跨主版本覆盖消除告警。

Web 首屏 JS 约 79 KB gzip，Firebase 和识别运行时独立懒加载。排行榜单次最多读取 20 个摘要，无逐用户全年历史查询。大型本地数据只按日期/类型索引读取当前需要的内容；这些是代码及模拟测试结论，不代表真机耗时或线上账单。

此前 Android 模拟器未被 ADB 识别；后续通过既有 ASCII 路径、先启动 ADB 并固定模拟器端口解决连接问题。API 36 模拟器上的 3 项原生集成测试、6 项安装版流程检查和真实重启恢复检查通过。覆盖实际通知及稍后提醒、记录持久化、返回键、系统文件导出和 APK 内模型推理，详见 [Android 安装版验收](V3_ANDROID_ACCEPTANCE.md)。本次仅扩充原生测试，业务输入和既有 APK 未改变；未重复执行原先通过的 40 项检查。测试模拟器进程已停止，没有连接或操作用户的实体手机。
